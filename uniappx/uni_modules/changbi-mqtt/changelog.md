## 1.1.4（2026-04-13）
### 新功能
### 
#### 连接状态管理
- 新增 `StateManager` 类管理连接状态
- 支持状态查询：disconnected、connecting、connected、reconnecting、disconnecting
- 状态变化自动触发相应事件
- 新增 `getConnectionState()` API 查询当前状态

#### 自动重连机制（需要授权 自启动）
- 新增 `ConnectionManager` 类管理重连逻辑
- 支持配置重连间隔（`reconnectPeriod`，默认 5000ms）
- 支持配置最大重连次数（`maxReconnectAttempts`，默认 10 次）
- 连接丢失自动触发重连
- 重连成功后自动恢复订阅
- 新增 `reconnect` 事件（重连开始时触发）
- 新增 `offline` 事件（达到最大重连次数时触发）

#### 连接保活（Keepalive）（需要授权 自启动）
- Eclipse Paho Android Service 内置支持
- 自动发送 PINGREQ 心跳包
- 自动处理 PINGRESP 响应
- 心跳超时自动触发重连

## 1.1.0（2026-04-11）
v1.1.0 (2026-04-11)

### 新增功能
- ✨ 实现 SubscriptionManager 订阅管理器
  - 维护订阅列表
  - 支持查询订阅状态
  - 防止重复订阅
  - 自动清理订阅

- ✨ 实现 MessageHandler 消息处理器
  - 消息队列管理
  - 待发送消息队列
  - 已接收消息队列
  - 队列大小限制（最大 1000 条）
  - 队列统计功能

- ✨ 增强订阅功能
  - 订阅前检查是否已订阅
  - 订阅成功后记录到管理器
  - 取消订阅时从管理器移除
  - 断开连接时清空订阅列表

- ✨ 新增辅助方法
  - `getSubscriptions()` - 获取所有订阅
  - `getSubscriptionCount()` - 获取订阅数量
  - `hasSubscription(topic)` - 检查是否已订阅
  - `getMessageQueueStats()` - 获取消息队列统计
  - `clearMessageQueues()` - 清空消息队列

- ✨ 完整的测试页面
  - 连接管理界面
  - 订阅管理界面（显示订阅列表和数量）
  - 消息发布界面（支持 QoS 和 retain）
  - 消息日志显示（实时显示接收的消息）
  - 队列统计功能
